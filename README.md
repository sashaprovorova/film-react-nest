# Film!

Веб-приложение для просмотра киноафиши и покупкой билетов, реализующее полный цикл:
frontend + backend + база данных + деплой в продакшен.

Проект демонстрирует работу с контейнеризацией, серверной инфраструктурой и возможностью смены базы данных без изменения бизнес-логики приложения.

## Описание проекта

Backend (REST API, реализующее бизнес-логику сервиса «Film!»)

Отвечает за:

- получение списка фильмов
- получение расписания сеансов
- отдачу контента
- Работает в отдельном Docker-контейнере
- Подключается к базе данных через переменные окружения

База данных

- В проекте предусмотрена возможность работы с разными СУБД
- Изначально backend был настроен для MongoDB
- В финальной версии используется PostgreSQL
- Переключение между MongoDB и PostgreSQL возможно без изменения кода — только через конфигурацию окружения

PostgreSQL автоматически инициализируется при первом запуске контейнеров с помощью SQL-скриптов:

- prac.init.sql — создание таблиц
- prac.films.sql — наполнение фильмами
- prac.schedules.sql — наполнение расписанием

## Архитектура и деплой

Проект полностью контейнеризирован и развёрнут на удалённом сервере.

Используемые технологии:

- Docker
- Docker Compose
- Nginx
- PostgreSQL
- GitHub Container Registry

Архитектура контейнеров

- frontend — сборка фронтенда
- backend — API-сервер
- db — PostgreSQL
- nginx — reverse-proxy и точка входа
- pgadmin — администрирование базы данных

Nginx:

- отдаёт frontend
- проксирует /api/\* на backend
- проксирует /content/\* на backend

⸻

## Сервер

- Виртуальная машина в Yandex Cloud
- Настроен firewall (открыт только порт 80)
- Подключено доменное имя
- Приложение запускается из готовых Docker-образов без сборки на сервере
- Обновление проекта выполняется через docker compose pull и docker compose up -d
